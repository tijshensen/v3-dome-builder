# Option B — Latex-cement Hex skin (PROTOTYPE)

**Status:** APPROVED PROTOTYPE (TPM 2026-09-06) — not production  
**Scope:** 2–3 prototype skins only. Does **not** replace wood Hex structure. Does **not** change the wood cut-list. Does **not** block wood Hex / assembly / deck gate.  
**Do not expand to 73** until TPM / Tijs authorizes a later run.

**Locked:**
- Role: skin/infill over finished wood Hex (1 triangle = 3 struts)
- Mold: outer plan triangle **1155 × 1155 × 1130 mm**  
  (= plan **3′-9 7/16″** sides / **3′-8 1/2″** base; 1155/1130 are rounded mm)
- Depth: **20 mm** (~2 cm); mesh at mid-plane (~10 mm)
- Edge: square face + mold draft **~1–2°** on walls only (no chamfer seat)
- Attach: bed + batten on **OUTSIDE** of wood Hex
- Qty: **2–3** prototypes  
  - Skin 1 = **process trial** (may not install)  
  - Skins 2–3 = **fit / install trials**

---

## 0. Safety
- Gloves, dust mask / respirator, goggles, ventilation
- **Cement dust + wet alkali:** wash skin ASAP if contact; rinse eyes with water and seek help if needed
- Mesh must be **alkali-resistant (AR) fiberglass only** — **no plain steel mesh** in cement
- Do not cast indoors without airflow

## 1. Materials (for 3 skins + ~15% waste)

| Item | Spec | Qty (approx) |
|------|------|--------------|
| Portland cement | Common bagged | ~20 kg |
| Fine clean sand | Dry, no clay | ~50 kg |
| Latex polymer | Prefer **SikaLatex** or **Chapix SBR Quartzolit** (SBR/acrylic). Fallback: Bianco Vedacit (PVA, weaker) | ~5 L concentrate |
| Water | Clean | ~5 L (for 1:1 dilute with latex) |
| Fiberglass mesh | **AR only**, ~4×4 mm | ≥2 m² (cut 3 triangles) |
| Mold sheet | Plywood / melamine / plastic | enough for 1 reusable mold |
| Release | **Form oil, paste wax, or mold release** (name which you use in mix notes) | as needed |
| Bed adhesive | Flexible **MS polymer** or **polyurethane** (not rigid epoxy) | 1–2 cartridges |
| Battens | Thin wood or aluminum | **≥3 per skin** (one per triangle edge) |
| Screws | Stainless, into wood strut **centerline** | small box |
| Perimeter sealant | Exterior-grade flexible | 1 cartridge |
| PP fibers (optional trial) | Short, 0.5–1% of cement mass | small pack |

**Do not use for latex substitute:** Tecplus 1 (mineral waterproofing only), Vedalit (plastifier only).

## 2. Mix ratio (base)
1. Dry: **1** Portland cement : **2–3** fine sand (use **1 : 2.5** for prototype)
2. Liquid: latex emulsion diluted **1:1** with water
3. Add liquid gradually to dry mix to a plastic, trowelable paste (not soup)

**Bianco fallback batch example** (if SBR unavailable):  
900 ml Bianco + 900 ml water + 4 kg cement + 10 kg sand ≈ 1 large or 2 smaller panels. Scale for your mold volume (~11.4 L per skin).

Optional lightening (side trial only on 1 of 3): replace part of sand with perlite/vermiculite; and/or add 0.5–1% PP fibers by cement mass.

## 3. Make the mold
1. Draw isosceles triangle: sides **1155 mm (3′-9 7/16″)**, base **1130 mm (3′-8 1/2″)** — long-point plan lengths.
2. Build cavity depth **20 mm**.
3. Add **~1–2° draft** on vertical walls so the panel releases cleanly. Keep the **face edge square** (no chamfer seat).
4. Apply named release: **form oil / paste wax / mold release**. Keep corners sealed so slurry does not leak.
5. Mark a mid-depth line at **~10 mm** for mesh placement.

One reusable mold is enough for 2–3 sequential casts.

## 4. Cut mesh
- Cut **AR fiberglass** mesh to the triangle, **~10–15 mm smaller** than the mold on each edge so mesh stays covered by cement.
- One layer per skin, centered.
- **No plain steel mesh.**

## 5. Cast one skin
1. Mix dry cement + sand thoroughly.
2. Dilute latex 1:1 with water; add to dry mix gradually.
3. Place a first layer ~10 mm in the mold; compact / trowel flat.
4. **Photo checkpoint:** mesh layer seated (no dry pockets).
5. Lay mesh; press gently so it seats in the wet layer.
6. Place second layer to **20 mm** total; trowel flat to mold rim.
7. Label the panel (date, mix notes, “prototype”, skin #1 process / #2–3 fit).

Repeat for skins 2 and 3. Keep mix notes: brand, ratio, release used, weather, cure start time.

## 6. Handling (green and cured)
- Each skin is about **20–23 kg** (estimate). Use a **two-person lift**.
- Support with **edge cradles** / flat supports. **Do not flex** a green panel.
- Demold only when edges will not break (often 24–48 h), then continue damp cure.

## 7. Cure
1. Cover damp (plastic + occasional mist). Keep moist.
2. Target **7+ days** damp cure before any install (conservative). Do not install green panels.
3. **Log target weight** after demold (and again before install if useful).

## 8. Install gate (required)
- Install **only** on a wood Hex that already **passed flip-test QA** (approved Hex fab).
- Skin **#1** = process trial — **may not install**.
- Skins **#2–3** = fit / install trials (only if gate passes).

## 9. Fit check (before bed)
1. Dry-place skin on finished, QA-passed wood Hex **outside** face.
2. Confirm coverage of strut faces; trim only if a local high spot blocks seating (keep plan geometry).
3. Confirm battens will catch panel edge + strut.

## 10. Install (bed + batten)
1. Clean strut contact faces.
2. Apply flexible **MS polymer** or **PU** bed on strut faces (not epoxy).
3. Set skin on the outside of the Hex; seat into bed.
4. Fit battens: **one retainer per triangle edge minimum** (**3 per skin**).
5. Drive **stainless screws into strut centerline**. Avoid splitting near **miter ears**.
6. Do not over-crush the cement edge.
7. Run exterior perimeter sealant. Leave a **movement gap** — no hard lock of cement to wood.
8. **Photo checkpoint:** after batten install.

## 11. Prototype pass / fail notes (report to TPM)
Record for each of the 2–3 skins:
- Mix brand + ratio + release used
- Demold time / cure days
- Weight after demold
- Cracks, warp, edge chips
- Fit on wood Hex (and flip-test Hex ID if labeled)
- Batten hold / sealant behavior
- Photos: mesh layer; after batten
